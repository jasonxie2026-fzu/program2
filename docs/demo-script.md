# 演示脚本（仅合成联系人）

演示前运行 `python3 app.py`，打开 `http://127.0.0.1:8765`。使用虚构资料，不录入真实个人通讯录。

1. 从 0 联系人空态新建“林晓（演示）”，添加电话“00123 / 工作”、第二个电话“+1 415 555 0199 / 海外”、两个邮箱、微信账号、地址、公司、备注并加入星标。
2. 保存后看总数、星标数和联系人卡片；点卡片打开详情，逐项展示标签和值；关闭后再次打开编辑，确认各行仍在。
3. 搜索微信账号，再清空搜索；打开星标视图，取消星标并确认计数/列表同步；刷新确认状态持久化。
4. 新建“陈一（演示）”，保留未星标。使用搜索分别按姓名和电话查找。
5. 导出 Excel，打开文件检查每位联系人一行、电话/邮箱/微信/地址各自分列、前导零为文本。
6. 选择该 Excel 导入；先展示预览和“追加、不自动去重”规则，再确认。刷新后检查导入计数和字段。
7. 在 320/390px 手机宽度展示导航、列表卡片和全屏表单；在桌面宽度展示侧边详情。
8. 测试完成后，用本地测试数据清理流程删除合成记录，再准备最终空态截图。

仓库的[演示材料](evidence/)使用虚构资料。十个实际运行画面依次展示空态、填写多项联系方式、详情、星标、筛选、导出、导入预览、确认结果、刷新和导入后的字段校验，并剪辑为[分步演示视频](evidence/address-book-demo.mp4)。如需补拍手机布局或对操作过程连续录屏，可用上面的步骤重跑。
