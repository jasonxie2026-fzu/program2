# 设计与数据决策

## 方向

保留「人间有信 / 把重要的人，好好留在身边」的中文语气，将现有通讯录整理成温暖、安静的纸本文具感。布局继续服务于搜索和联系人管理；不另造 landing page。

## 视觉令牌

| 角色 | 值 |
|---|---|
| 纸张背景 | `#F7F3EB` |
| 卡片纸白 | `#FFFCF6` |
| 墨绿文字/主操作 | `#15352F` |
| 次级墨绿 | `#556D64` |
| 鼠尾草强调 | `#8BA99A` |
| 星标珊瑚 | `#B84F40` |
| 暖金细节 | `#CDA16B` |
| 细线 | `#DBDFD5` |

字体以系统中文 sans-serif 为主、系统 serif 作少量英文强调；移除必需的远程字体请求，离线保持完整排版。常规正文按 16px 基准，保留 1.5 行高、4/8px 间距节奏、12–22px 圆角与轻柔静态阴影。

## 组件与交互

- 导航：全部/星标按钮显式选中态和计数；窄屏转为顶部可触控导航。
- Hero/统计：标题和品牌副文案优先，装饰限制在 hero 局部；计数随保存/星标同步。
- 联系人列表：整卡进入详情，星标独立操作；键盘可达，搜索结果即时更新并区分无结果与空通讯录。
- 详情：桌面右侧抽屉，手机全屏面板；显示所有联系方式、标签、备注、公司和地址；编辑、复制、星标动作可见。
- 编辑表单：联系人方法逐条添加/删除，可选择电话、邮箱、社交、地址或其他，输入类型/标签/值；继续接受旧 JSON 的 phones/emails/address 数据。
- Excel：姓名/星标/公司/备注为基础列；每个联系方式独立列、标签相邻；预览后确认追加导入，显示重复策略与成功/失败反馈。

## 动效与降级

单一 hero 氛围层采用低对比纸纹/光晕和 18 秒缓慢呼吸；列表入场最多前 8 行短促淡入；卡片 hover 仅 2–3px；星标按压使用 transform；抽屉使用 opacity/transform。减少动态模式关闭循环背景、位移和 stagger，保留立即可读状态；无 JS 动画也不阻断操作。背景层 `pointer-events:none`。

## 无障碍与数据

对话框使用原生 `<dialog>` 并提供关闭/取消/ESC、焦点归还；按钮具备名称与 `aria-pressed`；操作目标至少 44px；搜索尊重中文输入法 composition。长值换行，错误靠近对应字段并可读。收藏、列表、编辑和 Excel 保持真实数据流，不依赖动效。

## 依赖

新增运行时依赖：无。原生 HTML/CSS/JavaScript 和 Python 标准库足够，不引入 React、shadcn、Magic UI、Motion 或 React Bits。

## 未采用的外部设计建议

`ui-ux-pro-max` 的两个目标查询都返回企业销售/SaaS 方向，和产品任务不匹配；未使用其配色、字体或组件建议。`frontend-design` 在本机未安装；用户提及的额外 Skill 截图不在当前附件中，未猜测名称。
