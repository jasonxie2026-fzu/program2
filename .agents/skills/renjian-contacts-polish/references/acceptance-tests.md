# 验收矩阵：功能 > 视觉

以下为 Codex 必须执行的测试清单。在有真实浏览器/测试框架时尽量自动化；不可运行时将状态标为“未运行”，列出复现步骤，不能声称已验证。

## 核心功能

| ID | 用例 | 结果要求 |
|---|---|---|
| F01 | 首次打开 0 联系人 | 真正空态；新增按钮可操作；不永久显示“正在读取” |
| F02 | 新建联系人 A：1 电话 1 邮箱 | 列表、详情、统计同步；刷新保留 |
| F03 | A 追加第二电话、第二邮箱、微信、地址 | 编辑后所有值、类型和标签保留 |
| F04 | 标记 A 星标 | 星标计数 +1、图标状态正确、星标列表包含 A；刷新保留 |
| F05 | 取消 A 星标 | 计数 -1、星标列表移除 A、全部列表仍有 A |
| F06 | 新建联系人 B，搜索姓名/电话/邮箱 | 结果符合搜索；无结果有空态；清空搜索恢复 |
| F07 | 导出含 A/B 的 Excel | 一人一行；姓名/公司/电话1/电话2/邮箱1/邮箱2/微信/地址/收藏分别有列；下载可打开 |
| F08 | 将 F07 文件导入全新空测试数据 | 行数、字段、多联系方式、星标完全一致（允许生成新 id） |
| F09 | 导入错误扩展名/坏表头/空文件 | 页面解释错误；原数据无损；未卡死 |
| F10 | 导入相同数据第二次 | 明确重复策略、反馈数目，避免无意识重复 |
| F11 | 编辑/删除联系人 | 列表、收藏、搜索与统计同步；删除需要确认/可撤销策略 |
| F12 | 零联系人导出模板 | 导出合法空白模板或有明确可用模板行为 |
| F13 | 关闭页面重开/刷新 | 数据保留；用户能找到备份提醒 |

## UX/无障碍/性能

| ID | 检查项 | 通过条件 |
|---|---|---|
| U01 | 1440 / 768 / 390 / 320 px | 没有横向溢出、遮挡或不可点击操作 |
| U02 | Keyboard Tab / Enter / Esc | 可达星标、搜索、新建、导入、编辑、关闭详情；焦点明显、关闭面板返回触发点 |
| U03 | reduced motion | 无持续漂浮/视差、重要反馈仍可读、没有因 opacity 造成空白 |
| U04 | 200+ 联系人 | 搜索、星标、列表切换不会明显卡顿、动效不会逐条长时间播放 |
| U05 | 色彩可读性 | 正文/背景对比满足 WCAG AA 目标、错误和收藏不只靠颜色 |
| U06 | 控件 | 手机端常用按钮触控区域约 44×44px，错误字段和加载状态有文字辅助 |
| U07 | 稳定性 | 无 console error、构建/测试通过、无破坏性数据迁移 |
| U08 | 视觉一致性 | 纸张底色、标题、按钮、抽屉、表单与空态统一，不混用多套强视觉效果 |
