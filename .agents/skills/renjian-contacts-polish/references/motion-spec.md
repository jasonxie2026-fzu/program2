# 动效系统：丰富的触点，受控的舞台

只把动效用于表达层级、反馈与状态变化，不把通讯录变成烟花。

| 交互 | 方案 | 建议时长 | 失败/无动画回退 |
|---|---|---:|---|
| 初次进入/切视图 | Hero 轻淡入 + y 6–12px；内容分组短暂延迟 | 250–450ms | 立即完整展示；不能阻塞列表 |
| 切换全部/星标 | 内容 crossfade + 小幅位移；有真实 key 的列表可用 FLIP | 220–360ms | 直接替换；保留焦点/语义 |
| Hover 联系人卡 | 上浮 2–3px，边框/阴影淡入 | 160–220ms | 仅 border/focus 样式 |
| 点击星标 | scale 0.92→1.18→1 与填充切换；计数同步 | 220–300ms | 立即切换图标状态，保留 `aria-pressed` |
| 新建/详情 Drawer | 右侧/底部轻滑入 + overlay 淡入 | 260–380ms | 直接显示可操作面板；焦点陷阱/返回焦点 |
| 多联系方式新增行 | 高度/opacity/translate 组合 | 180–280ms | 直接新增，屏幕阅读器可感知 |
| 搜索结果 | 轻交叉淡入，不做逐字酷炫动效 | 120–200ms | 立即更新结果与数量 |
| 导入/导出反馈 | 加载/完成状态小图标、进度/行数 | 160–280ms | 可读文本状态、错误行号、下载链接 |
| 背景 | 仅 Hero 内的网格呼吸或低幅度慢漂浮；**最多一个连续场景** | 12–24s 循环 | 静态纸张/点阵纹理 |

## 实现规则

- 定义统一时间/曲线 tokens，如 `--duration-fast: 160ms`, `--duration-base: 240ms`, `--duration-slow: 360ms`, `--ease-out: cubic-bezier(.22,1,.36,1)`。
- 优先 animating `transform` 与 `opacity`；避免大面积 `filter: blur()`、`box-shadow` 连续变化、滚动帧中频繁读写布局。
- 动画只在可见组件运行，长列表利用分页/窗口化与短入场，不要一次给 200 张卡片触发 stagger。
- `prefers-reduced-motion: reduce` 下移除循环动画与夸张位移，过渡 <=50ms 或直接关闭。不要使内容处于 opacity:0。
- 所有按钮保留键盘 `:focus-visible`；收藏使用 `aria-pressed`，动态状态可用 `aria-live="polite"`（不要重复播报）。
- 触摸设备不依赖 hover；兼容键盘、滚动与输入法；不可将事件只绑定动画层。
- canvas/WebGL 若使用，必须在可见区域启动、离开/卸载时清理、设备低配时降级，禁止遮挡点击/焦点。无条件禁用装饰层的 pointer-events。

## 性能检查

- 本地浏览器记录页面加载、长列表搜索（100+ 甚至 500 联系人）、编辑/星标/导入时的响应性；不要在内存不足时大量动画。
- 优先打包体积可控，避免引入几套重复 animation 库；**不是为了高星数而装依赖**。
- 快速验收：移动端 390px 触摸、Chromium reduced motion、键盘 Tab、数据列表 200 条下的交互不卡顿。
