# 人间有信｜通讯录

一个在本机运行的通讯录应用。支持新增、编辑、删除、搜索和星标联系人；每人可以保存多个电话和邮箱，也可以通过 Excel 批量导入或导出。

## 运行

需要 Python 3.10 或以上版本，不需要安装第三方依赖。

```bash
python app.py
```

浏览器会自动打开 `http://127.0.0.1:8765`。如未自动打开，请手动访问该地址。按 `Ctrl+C` 停止服务。端口被占用时，可设置环境变量 `ADDRESSBOOK_PORT` 后重新运行。

联系人保存在项目的 `data/contacts.json` 中。服务只监听本机地址；请自行备份数据文件。

## Excel 导入与导出

点击“导出”可获得 `.xlsx` 文件；即使通讯录为空，也可以将导出的文件作为导入模板。列顺序为：姓名、电话、邮箱、公司、地址、备注、收藏。姓名必填；多个电话或邮箱在单元格中换行，或用分号分隔。收藏填写“是”或“否”。

导入会追加联系人，不会自动去重或覆盖现有记录；如有错误，整批不会写入。当前支持 `.xlsx` 的第一个工作表，不支持旧版 `.xls`。导入前建议备份。

## 测试

```bash
python -m unittest discover -s tests -v
```

## 结构

- `app.py`：HTTP 服务、数据存储、Excel 文件读写。
- `static/`：页面、样式和交互。
- `tests/`：关键数据行为测试。
- `博客草稿.md`：基于已完成内容的博客草稿，需补充真实个人信息、分工、记录和截图。
